## About me

I'm an AI Engineer and Software Developer based in Frankfurt, Germany. My work combines product development with model evaluation: I build the application, the API, the data flow, and the tests needed to understand whether an AI feature is actually useful.

My current focus is German-language NLP, CEFR analysis, human-in-the-loop review systems, and dependable AI product workflows.

## Selected work

### LinguBase

A free German sentence-level CEFR estimation tool for A1–C2.

- Analyzes German sentences and returns a CEFR level estimate with supporting signals.
- Supports single-sentence and batch analysis.
- Separates inference, human review, dataset preparation, and model release decisions.
- Includes teacher correction proposals and admin approval workflows.
- Uses evaluation sets and regression tests to investigate changes in engine behavior.

**Stack:** React, TypeScript, Tailwind CSS, Node.js, Express, PostgreSQL, Supabase, Docker, Google Cloud Run, Netlify, Jest.

<a href="https://lingubase.netlify.app">Open LinguBase</a>

### BerufDeutsch

A professional German learning platform with generated exercises and validation workflows designed to check model output before it reaches learners.

### PetSense

A pet-care product exploring browser-based vision analysis. The basic photo-analysis step is designed to run on the device for that workflow.

## Engineering principles

- Evaluate model behavior against simple baselines.
- Test boundary cases and disagreements, not only average scores.
- Add regression checks before changing analysis rules.
- Keep model predictions, expert feedback, training data, and deployment decisions separate.
- Build interfaces that make AI results understandable to users.
